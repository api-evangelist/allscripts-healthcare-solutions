# Allscripts Healthcare Solutions (now Veradigm)

> Allscripts Healthcare Solutions renamed itself Veradigm in 2022 and sold its hospital and
> large-physician-practice business (Sunrise, Paragon, TouchWorks) to Harris Computer, now Altera Digital
> Health. allscripts.com redirects to veradigm.com. The developer program is the Veradigm Connect Developer
> Program at developer.veradigm.com. Two API estates exist: a public HL7 FHIR R4 (4.0.1) surface serving
> USCDI data for 21st Century Cures Act patient and provider access, authorized with SMART App Launch
> 2.0.0; and the proprietary bidirectional Unity API, which is the only surface that can write patient
> demographic, appointment or financial data and which requires a paid Integrator subscription. Veradigm
> publishes no OpenAPI, no MCP server, no A2A agent card, no llms.txt of its own, and no public client SDK.
>
> GENERATED by API Evangelist from the artifacts in this repository. This is an independent third-party
> profile; it is not published by Veradigm.

## What is actually callable

- [FHIR R4 CapabilityStatement (live, fetched 2026-09-01)](https://raw.githubusercontent.com/api-evangelist/allscripts-healthcare-solutions/refs/heads/main/fhir/allscripts-healthcare-solutions-veradigm-fhir-r4-capabilitystatement.json): The machine-readable contract. 31 FHIR resources; read and search on all of them; create and update on twelve; delete on none; zero declared operations.
- [Veradigm EHR R4 sandbox base URL](https://fhir.fhirpoint.open.allscripts.com/fhirroute/fhir/CP00101/): Veradigm's own published sandbox. `GET {base}/metadata` answered HTTP 200 unauthenticated.
- [Veradigm Endpoint Directory](https://developer.veradigm.com/Fhir/EndpointDirectory): Production base URLs are PER CUSTOMER ORGANIZATION. Downloadable as an NDJSON FHIR Bundle of Organization resources, or CSV. Endpoints ending `/fhir` are provider-facing; endpoints ending `/open` are patient-facing.

## Rules an agent has to know before it calls

- [API conventions](https://raw.githubusercontent.com/api-evangelist/allscripts-healthcare-solutions/refs/heads/main/conventions/allscripts-healthcare-solutions-conventions.yml): Content negotiation selects the FHIR release. A date search with no comparison operator means EXACT MATCH. `_include` resources repeat on every page. NO idempotency key is documented anywhere.
- [Error catalog](https://raw.githubusercontent.com/api-evangelist/allscripts-healthcare-solutions/refs/heads/main/errors/allscripts-healthcare-solutions-problem-types.yml): 401, 403, 404, 413, 429. Envelope is FHIR OperationOutcome, not RFC 9457 problem+json. A 200 may contain elements marked "redacted" - redacted is NOT null.
- [Rate limits](https://raw.githubusercontent.com/api-evangelist/allscripts-healthcare-solutions/refs/heads/main/rate-limits/allscripts-healthcare-solutions-rate-limits.yml): No numeric limit is published. The only runtime signal is Retry-After on bulk-export polling; violating it returns 429.
- Reversibility: exactly ONE reversal path exists in this API - DELETE on a bulk export's Content-Location URL, with no stated window. Twelve resources accept create and update; NONE accept delete. Treat every clinical write as permanent.

## Known absences (checked 2026-09-01, not assumed)

- No OpenAPI or Swagger document on any host. FHIR CapabilityStatement is the contract.
- No MCP server - hosted or stdio. See mcp/ for a derived candidate tool surface with `deployment.mode: none`.
- No A2A agent card at /.well-known/agent-card.json or /.well-known/agent.json on any host.
- No security.txt, no api-catalog, no ai-plugin.json, no AAuth resource document.
- No public client SDK on npm, PyPI or NuGet. Both GitHub orgs (allscriptshealthcare, veradigm) have ZERO public repositories.
- No public Postman collection, no changelog, no CLI, no webhook or AsyncAPI event surface.
- No published SLA, and no security/compliance certification page could be read - veradigm.com returns HTTP 403 to non-browser clients.
